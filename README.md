# snapbuild

Каркас единого лендинга снэпбилд на React, Vite, TypeScript и Tailwind CSS. Структура подготовлена по `SPEC.md`; визуальная и интерактивная реализация секций будет добавляться поверх этого каркаса.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки перед публикацией:

```bash
npm run lint
npm run typecheck
npm run build
```

## Стек

- React + TypeScript
- Vite
- Tailwind CSS v4
- FSD-слои `app / widgets / shared`
- GitHub Pages через GitHub Actions

## Архитектура

```text
src/
├── app/
│   ├── styles/        # глобальные токены и адаптивная fluid-система
│   └── ui/            # композиция страницы
├── widgets/           # самостоятельные секции лендинга
└── shared/
    ├── assets/        # общие изображения и иконки
    ├── lib/fluid/     # calc(N / base * 1vw)
    └── ui/Section/    # full-bleed оболочка секций
```

Порядок виджетов соответствует SPEC:

```text
header → hero → logos → process → use-cases → roles → compare →
pricing → testimonials → features → onboarding → roadmap → faq →
demo-form → cta → footer
```

## Пять новых секций

1. Кейсы по ролям — `widgets/roles`.
2. Тарифы — `widgets/pricing`.
3. Отзывы — `widgets/testimonials`.
4. Этапы внедрения — `widgets/onboarding`.
5. Форма запроса демо — `widgets/demo-form`.

## Стилистические решения

- Используется только пространство классов `dds-*`; шаблонные `.card`, `.pricing-card`, `.testimonial-card`, `.stat-card` и `.btn-primary` не используются.
- Секции full-bleed и не ограничены общим `max-width`.
- Отступы и размеры рассчитываются через `calc(N / base * 1vw)` для макетов 375, 810 и 1440 px.
- Единственный цветной акцент — брендовый оранжево-розово-фиолетовый градиент.
- Карточки разделяются заливкой и тонкой рамкой без теней.
- Для точного воспроизведения исходной типографики подключены предоставленные сайтом файлы TT Commons Pro. Перед публикацией публичного репозитория необходимо отдельно подтвердить право на распространение этих файлов; безопасная замена — Manrope.

## Текущий статус и осознанные ограничения

Основные секции исходного лендинга перенесены, а новые секции из SPEC реализованы как самостоятельные FSD-виджеты. Тарифы содержат интерактивный расчёт месячной и годовой цены и оригинальные тематические изображения, созданные для тестового задания с помощью OpenAI ImageGen.

Пока не воспроизведены `large-screens.css` для экранов шире 1440 px, мобильный лайтбокс и cookie-баннер. Это соответствует приоритетам SPEC для проверяемых ширин 1280, 768 и 375 px.

Цены и отзывы из SPEC являются вымышленными. Демо-форма имитирует успешную отправку с задержкой 600 мс и не выполняет серверный запрос.

## Публикация

Vite настроен с `base: '/snapbuild-test-task/'`. Workflow `.github/workflows/deploy.yml` собирает проект и публикует каталог `dist` в GitHub Pages после push в `main`.

Ссылка на опубликованную версию будет добавлена после создания публичного репозитория и первого деплоя.

Codex использован для анализа тестового задания и SPEC, проектирования FSD-структуры и создания стартовой конфигурации проекта. Все решения и сгенерированный код должны быть проверены перед сдачей.
